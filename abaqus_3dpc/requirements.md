# 3D打印混凝土Abaqus模型 - 需求分析

## 项目目标
创建一个参数化的3D打印混凝土（含钢筋网）Abaqus模型，模拟打印过程和力学测试。

## 核心需求

### 1. 几何建模
- **打印构件**：长方体/梁结构（可参数化尺寸）
- **钢筋网**：双层钢筋网，可配置间距和直径
- **打印层**：分层建模，支持层间粘结设置

### 2. 材料模型
- **混凝土**：
  - 弹性模量（时变）
  - 抗压强度
  - 层间粘结强度（Cohesive行为）
  - 热膨胀系数
- **钢筋**：
  - 弹性模量
  - 屈服强度
  - 理想弹塑性

### 3. 打印过程模拟
- **单元激活**：使用Model Change或Element Birth/Death
- **时间步控制**：每层打印时间
- **温度场**：可选的热-力耦合

### 4. 力学测试
- **三点弯曲试验**
- **压缩试验**
- **结果提取**：应力-应变曲线、裂缝模式

## 技术约束
- Abaqus 2021
- Python 2.7（Abaqus内置）
- 无中文注释（编码兼容）

## 文件结构
```

```

## 关键参数
| 参数 | 默认值 | 说明 |
|------|--------|------|
| beam_length | 300.0 | 梁长度(mm) |
| beam_width | 100.0 | 梁宽度(mm) |
| beam_height | 50.0 | 梁高度(mm) |
| layer_height | 10.0 | 打印层厚(mm) |
| rebar_diameter | 6.0 | 钢筋直径(mm) |
| rebar_spacing | 50.0 | 钢筋间距(mm) |
| concrete_E | 30000.0 | 混凝土弹性模量(MPa) |
| steel_E | 200000.0 | 钢筋弹性模量(MPa) |
